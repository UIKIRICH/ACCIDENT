# 通衢慧判——交通事故辅助研判平台

这是一个面向交通事故辅助研判场景设计的可交互动态网站。

平台围绕“事故材料接入—多模态证据处理—智能分析—责任建议—规则依据—人工复核—结果归档”的完整业务流程进行设计，支持视频、图像、文本及规则信息的统一展示与交互，并预留真实后端接口，方便后续接入算法服务和业务系统。

## 一、主要页面

当前 已覆盖：

- 登录 / 注册
- 首页总览
- 事故录入
- 视频处理
- 视频抽帧管理
- 图片侧证
- 智能分析
- 责任建议
- 规则依据
- 人工复核
- 历史案例
- 任务中心
- 规则库管理
- 移动端采证
- 系统状态 / 处理进度
- 分析报告与结果归档

## 二、核心功能

### 1. 事故材料接入

支持事故基础信息录入，以及视频、图片等事故材料的上传、预览和管理。

包括：

- 事故信息表单录入
- 草稿保存
- 文件拖拽 / 点击上传
- 图片及视频材料统一管理
- 文件状态提示
- 材料哈希信息预留
- 移动端辅助采证入口

### 2. 视频处理与抽帧

针对事故视频提供可视化处理流程，包括：

- 视频上传与播放
- 视频处理状态展示
- 关键帧自动 / 手动切换
- 抽帧结果管理
- 关键证据帧选择
- 视频时间轴定位
- 处理任务进度展示

### 3. 图片侧证

支持事故现场图片、视频关键帧等视觉证据的统一展示与辅助分析。

可用于：

- 图片证据浏览
- 关键区域查看
- 不同证据之间交叉比对
- 侧证结果展示
- 多模态证据补充

### 4. 智能分析

提供事故材料的智能分析结果展示，包括：

- 车辆及目标识别结果
- 轨迹及行为信息展示
- 多源证据信息汇总
- 事故类型辅助分析
- 风险指标展示
- 多模态一致性检测
- 异常及冲突信息提示

### 5. 责任建议

根据已有证据、规则和模型分析结果生成辅助责任建议。

界面支持：

- 建议结果展示
- 判断依据说明
- 置信信息展示
- 证据链查看
- 风险提示
- 自动处理 / 人工复核 / 补充证据等状态展示

平台强调“辅助研判”，最终结果仍可进入人工复核流程。

### 6. 规则依据

提供与分析结果对应的规则依据展示，包括：

- 相关规则检索
- 条款内容查看
- 规则与事故行为对应关系
- 责任建议依据说明

### 7. 人工复核

对于需要人工参与的结果提供独立复核页面。

支持：

- 查看算法分析结果
- 查看证据链
- 确认当前结果
- 修改研判结果
- 填写修改原因
- 提交复核结论
- 复核记录归档

### 8. 规则库管理

支持规则信息的维护与管理，包括：

- 规则新增
- 编辑
- 删除
- 分类
- 搜索
- 状态管理

便于后续接入真实交通规则知识库。

### 9. 历史案例

支持历史事故案例的统一查询与管理，包括：

- 条件筛选
- 关键词搜索
- 案例详情查看
- 历史研判结果查看
- 人工复核记录查看

### 10. 任务中心

统一展示平台中的处理任务，包括：

- 待处理任务
- 正在处理任务
- 已完成任务
- 异常任务
- 任务进度
- 状态提示

### 11. 报告与结果归档

支持将事故处理过程和分析结果整理为结构化报告，包括：

- 事故基本信息
- 视频 / 图片证据
- 智能分析结果
- 责任建议
- 规则依据
- 人工复核结论
- 处理时间及状态信息

并预留报告导出功能。

## 三、交互特性

当前前端支持：

- 单文件入口 SPA
- 侧边导航切换
- 深色 / 浅色主题切换
- 表单录入与草稿保存
- 文件拖拽上传
- 图片及视频预览
- 关键帧切换
- 抽帧结果浏览
- 历史案例筛选
- 规则检索
- 人工复核操作
- 任务状态切换
- Toast 消息提示
- 弹窗确认
- 响应式页面布局

## 四、系统流程

平台主要业务流程为：

事故录入
↓
视频 / 图片材料接入
↓
视频处理与关键帧提取
↓
多模态证据组织
↓
智能分析
↓
责任建议
↓
规则依据匹配
↓
自动处理 / 人工复核 / 补充证据
↓
结果确认
↓
报告生成与历史归档
